# AI Chat Bot Interface

A modern, floating chat interface built with React and TypeScript. This project provides a beautiful and responsive chat UI that can be integrated with any AI backend.

## Features

- 💬 Floating chat interface
- 🎨 Modern UI with Tailwind CSS
- 📱 Fully responsive design
- ⚡ Built with Vite
- 🔍 TypeScript support
- 🎯 ESLint configuration
- 🎨 Lucide React icons

## Getting Started

1. Clone the repository:
   ```bash
   git clone [your-repo-url]
   cd [your-repo-name]
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
